# Клинок — барбершоп

Учебный фронтенд по теме «Барбершоп» для работ 9–11. Автор: Волков Матвей.

## Страницы

- `index.html` — главная: услуги, подход, мастера, галерея образов и карта адреса;
- `catalog.html` — каталог услуг и цен с фильтром;
- `product.html` — подробная страница услуги «Стрижка + борода»;
- `masters.html` — мастера;
- `order.html` — демонстрационная форма записи.

Откройте `index.html` в браузере. Сборка, Node.js и база данных не требуются. Bootstrap 5.3.3 и шрифты загружаются из CDN; фотографии лежат локально в `assets/`.

В шапке каждой страницы есть переключатель тёмной и светлой темы. По умолчанию остаётся исходная тёмная палитра; выбор сохраняется в браузере.

Форма позволяет выбрать услугу, мастера, дату и время, но **не создаёт заявку**. Для настоящей записи используйте телефон +7 (495) 120-22-00.

Адрес: Москва, Малая Филёвская улица, 18. Он показан в подвале всех страниц и отмечен на карте главной страницы. Контакты в подвале: +7 (495) 120-22-00 и hello@blade.ru.

Имена мастеров, цены, описания и фотографии — демонстрационный контент. Перед публикацией замените их на сведения барбершопа.
