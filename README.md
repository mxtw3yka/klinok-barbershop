# Клинок

Сайт барбершопа «Клинок». Посетители знакомятся с мастерами, услугами и ценами, смотрят примеры работ и находят адрес на карте. Выбор услуги, мастера, даты и времени показан в демонстрационной форме; для настоящей записи можно позвонить по телефону.

Сайт: [mxtw3yka.github.io/klinok-barbershop](https://mxtw3yka.github.io/klinok-barbershop/).

## Страницы

- `index.html` — главная страница;
- `catalog.html` — услуги и цены;
- `product.html` — услуга «Стрижка + борода»;
- `masters.html` — мастера;
- `order.html` — демонстрационная форма записи.

## Технологии

- HTML5;
- Bootstrap 5;
- CSS3;
- JavaScript.

## Медиа

Фотографии сайта хранятся локально в `assets/`, поэтому изображения не зависят от внешних фотосервисов. Bootstrap и шрифты загружаются через CDN.

Снимки в карточках мастеров иллюстративные, а не фотографии реальных сотрудников.
